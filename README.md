# Atividade de Layse - Cadastro de contato

## Requisitos das próximas telas
- **Tela de Listagem de Contatos**
  - Exibir todos os contatos cadastrados.
  - Permitir busca por nome, e-mail ou telefone.
  - Ordenar contatos em ordem alfabética.


- **Tela de Detalhes do Contato**
  - Visualizar informações completas do contato.
  - Exibir foto, nome, telefone, e-mail e observações.
  - Disponibilizar opções de editar e excluir.


- **Tela de Edição de Contato**
  - Alterar dados já cadastrados.
  - Atualizar foto do contato.
  - Salvar ou cancelar alterações.


- **Tela de Favoritos**
  - Exibir contatos marcados como favoritos.
  - Permitir adicionar ou remover favoritos.


- **Tela de Categorias**
  - Criar categorias como Família, Amigos, Trabalho e Clientes.
  - Associar contatos a uma ou mais categorias.


- **Tela de Grupos**
  - Criar grupos de contatos.
  - Adicionar e remover membros dos grupos.

- **Tela de Aniversários**
  - Exibir aniversariantes do mês.
  - Gerar lembretes para datas próximas.


- **Tela de Pesquisa Avançada**
  - Filtrar contatos por categoria.
  - Filtrar por cidade, empresa ou data de cadastro.

  
- **Tela de Importação e Exportação**
  - Importar contatos via arquivo CSV ou Excel.
  - Exportar contatos para backup.


- **Tela de Configurações**
  - Alterar tema (claro/escuro).
  - Configurar backup automático.
  - Gerenciar preferências do usuário.
